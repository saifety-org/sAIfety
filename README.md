# sAIfety

Офлайн-инструмент, который стоит между AI-агентом и его вводными данными и
проверяет их на инъекции промптов и опасные действия до того, как они попадут
в контекст модели.

## Как это работает

sAIfety анализирует каждый фрагмент вводных данных (файлы репозитория, ответы
MCP-инструментов, инструкции агента) статическим конвейером и по уровню угрозы
либо предупреждает, либо вычищает инструкции, либо блокирует источник. Ничего
не выполняется — команды разбираются, а не запускаются.

Конвейер: нормализация текста → рекурсивное декодирование скрытых слоёв →
детекторы → политика → вердикт.

- **Нормализация.** NFKC, удаление zero-width и bidi-символов, сворачивание
  Unicode-омоглифов в ASCII (полная таблица confusables).
- **Декодирование.** base64/base32/hex/url, escape-последовательности,
  HTML-сущности, char-коды, склеенные и JSON-строки, rot13, gzip/zlib —
  рекурсивно, чтобы найти инструкции в закодированных блоках.
- **Детекторы.** Инъекции и подделка системных сообщений (en/ru), опасные
  команды через настоящий парсер bash с анализом data-flow (утечка секретов в
  сеть, `curl | sh`, редирект в `/dev/tcp`), скрытый текст, закодированные
  блоки, опасные конфиги агента, текст в метаданных изображений и SVG,
  приманки на прерывание анализа (abort_bait) обезвреживаются, а скан
  продолжается, чтобы поймать нагрузку за ними.
- **Обезличивание.** Секреты и персональные данные (ключи, токены, e-mail,
  телефоны, карты, IP) маскируются в выводе инструментов и ответах MCP.
- **Целостность MCP.** Прокси ловит подмену инструментов (rug-pull), коллизии
  имён и cross-origin в описаниях.
- **Классификатор атаки на агента.** По умолчанию — встроенная обученная модель
  (логистическая регрессия на своих сгенерированных данных, многоязычная, без
  скачивания). Отличает вредоносную инструкцию агенту от легитимных команд
  проекта. Опционально — трансформер DeBERTa (`classifier: onnx`).
- **Кросс-файловый анализ.** Инструкции, разрезанные по нескольким файлам, и
  слабые сигналы, размазанные по репозиторию, ловятся на сводном проходе.

По умолчанию режим максимально строгий, классификатор — встроенная модель
`trained`. Поле `classifier` в конфиге позволяет выбрать `lexical` или `onnx`.

## Сценарии использования

1. **Проверка репозитория до запуска агента.** `saifety scan <dir>` сканирует
   все файлы; код возврата равен максимальному уровню угрозы, поэтому команду
   можно ставить в CI или в обёртку запуска.
2. **Единая точка входа для MCP.** Агент подключается только к `saifety proxy`,
   который проксирует настоящие MCP-серверы и фильтрует их ответы и описания
   инструментов.
3. **Хуки Claude Code.** `saifety hook` подаёт проверенные инструкции в контекст,
   запрещает доступ к заблокированным источникам и подменяет вывод инструментов.
4. **Перехват конфига MCP-клиента.** `saifety install` забирает все MCP-серверы
   клиента под свой прокси одной командой. Поддержаны Claude Code, Claude Desktop,
   Cursor, Windsurf, VS Code. См. [docs/configuration.md](docs/configuration.md).

## Установка

**1. Готовый бинарник (без Go).** Скачивает бинарник под вашу ОС и кладёт в каталог
из PATH:

```sh
curl -fsSL https://raw.githubusercontent.com/saifety-org/sAIfety/main/scripts/install.sh | sh
```

Это чистый Go-бинарник (встроенный классификатор плюс все правила, декодер, shell,
обезличивание) — работает офлайн, без зависимостей. Требует опубликованного релиза
проекта.

**2. Из исходников, глобально.** Нужен Go 1.26+; для варианта с трансформером ещё
C-компилятор (clang/gcc):

```sh
sudo make install-bin                          # в /usr/local/bin (уже в PATH)
# или без sudo, в домашний каталог:
PREFIX=$HOME/.local make install-bin           # затем добавьте ~/.local/bin в PATH
```

`/usr/local/bin` уже в PATH по умолчанию, но на macOS обычно принадлежит root —
поэтому нужен `sudo` (либо ставьте в `PREFIX=$HOME/.local`). При отказе в правах
`make install-bin` сам подскажет оба варианта. Есть также `make install` (через
`go install` в `$(go env GOPATH)/bin` — этот каталог нужно добавить в PATH вручную).

**Обновление одной командой.** Пересобрать, установить глобально и проверить:

```sh
sudo make update        # build + install в /usr/local/bin + verify (MATCH)
make reset-state         # по желанию: сбросить накопившиеся ложные блокировки/пины
```
После обновления перезапусти Claude, чтобы прокси поднялся на новом бинарнике.

**3. Только сборка, без установки.**

```sh
make build          # bin/saifety с трансформером (нужен C-компилятор)
make build-lite     # чистый Go, встроенный классификатор, ничего не качает
```

**Трансформер против lite.** Готовый бинарник и `*-lite` используют быстрый
встроенный классификатор и все детекторы; они работают офлайн. Вариант
`make build`/`make install` также поддерживает `classifier: onnx` и скачивает
DeBERTa (~738 МБ) при первом использовании этого режима; при недоступности
модели откатывается на лексику. Поддерживаются macOS и Linux (x86_64/arm64).

## Быстрый старт

```sh
saifety scan ./repo            # скан каталога со встроенным классификатором
saifety scan -deep ./repo      # также использовать доступную PII NER-модель
```

`scan` с настройками по умолчанию не требует скачивания модели.

## Просканировать и запустить агента

`saifety launch` сканирует текущую папку и, если нет критичных угроз, запускает
Claude уже под защитой (через прокси и хуки sAIfety):

```sh
cd ~/projects/my-repo
saifety launch                 # scan cwd → если чисто, запустить claude здесь
saifety launch -- --model opus # аргументы после -- уходят в claude
saifety launch -force          # запустить даже при критичных находках
```

Это и есть тот самый flow «`saifety && claude`»: при критичной угрозе агент не
стартует, иначе — стартует в этом репозитории. Для голого запуска без прокси есть
шелл-цепочка `saifety scan -fail-on critical && claude`.

## Установка в MCP-клиент (одна команда)

Чтобы агент сразу работал через sAIfety, отдайте ему свои MCP-серверы под прокси:

```sh
bin/saifety install claude-code    # или claude-desktop, cursor, windsurf, vscode, all
```

Команда переносит все MCP-серверы клиента под прокси sAIfety, делает резервную
копию и печатает путь к ней. Перезапустите клиент — готово. Откат: `bin/saifety
uninstall claude-code`. Сначала можно посмотреть, что изменится: добавьте `-dry-run`.

## Многоязычная модель ПДн (опционально)

Секреты и ПДн маскируются эвристиками сразу. Чтобы дополнительно ловить имена
без явной структуры на многих языках, скачайте NER-модель (нужна сборка `make build`):

```sh
bin/saifety model pull         # тянет модель инъекций и многоязычную PII-модель
bin/saifety model status       # что скачано и готово
```

## Команды

```sh
bin/saifety scan -format json ./repo      # для CI (есть также -format sarif)
bin/saifety scan -deep ./repo             # также включить доступную PII NER-модель
bin/saifety statistics                    # счётчики угроз (scan/proxy/hook раздельно)
bin/saifety proxy                         # MCP-прокси (stdio)
bin/saifety launch ./repo -- --model opus # scan + запуск claude с прокси и хуками
bin/saifety install cursor -dry-run       # предпросмотр перехвата конфига
```

Коды возврата `scan`: 0 чисто, 1 base, 2 medium, 3 critical, 64 ошибка
аргументов, 70 сбой.
