Это внешний benchmark по авторским меткам, а не универсальный рейтинг. Полное отсутствие пересечений с обучением DeBERTa не установлено. BIPIA содержит инструкции, чья вредоносность зависит от контекста. Многоязычный срез содержит только безопасные примеры. Скорость относится к данной CPU-реализации с batch=1, не к оптимизированному GPU/batch inference. Интервалы Wilson приведены как описательные; корреляции внутри семейств учитываются отдельно групповым bootstrap.
