# Статус реализации по idea.md

Сопоставление предложений из [idea.md](idea.md) с текущим кодом.
Легенда: ✅ готово · 🟡 частично · ❌ нет.

## Требования

| Предложение | Статус | Где / примечание |
|---|---|---|
| Работа как MCP-прокси для вводных данных | ✅ | `saifety proxy` агрегирует апстримы, фильтрует ответы и описания инструментов |
| Офлайн-анализатор, набор угроз заранее | ✅ | правила и детекторы встроены; модель качается один раз в кэш, дальше офлайн |

## Виды угроз и обнаружение

| Предложение | Статус | Где / примечание |
|---|---|---|
| Context poisoning: как понять, что контекст отравлен | ✅ | детекторы инструкций + классификатор (DeBERTa/лексический) + сводный проход |
| Явные вредоносные инструкции | ✅ | детектор `instruction`, категории override/system_prompt |
| Удаление данных | ✅ | shell-детектор, категория `deletion` |
| Зашифрованные / закодированные инструкции | ✅ | рекурсивный декодер (base64/hex/url/escapes/gzip/…), категории `encoded_payload`, `encryption` |
| Любые не человеко-понятные данные | 🟡 | ловятся закодированные и скрытые (zero-width, bidi, гомоглифы); произвольный «шум» — эвристиками |
| Вызовы внешних систем (curl, ssh, sftp, ftp) | ✅ | shell-детектор с анализом data-flow, категории `exfiltration`, `remote_exec` |
| Переопределение инструкций | ✅ | `instruction_override` (en/ru) |
| Системные промпты | ✅ | `system_prompt` (поддельные chat-теги, шаблоны, harness-теги) |

## Взаимодействие с агентом (уровни)

| Предложение | Статус | Где / примечание |
|---|---|---|
| Критерий разделения уровней | ✅ | политика: ущерб × уверенность × доверие к источнику |
| Базовый: предупреждение, данные оборачиваются | ✅ | `sanitize` действие warn |
| Средний: инструкции удаляются до передачи | ✅ | `sanitize` действие strip |
| Критичный: источник блокируется, доступ по ручному подтверждению | ✅ | действие block + блок-лист (`~/.local/state/saifety`) |

## Бизнес-логика

| Предложение | Статус | Где / примечание |
|---|---|---|
| BERT-подобная модель поиска инструкций | ✅ | DeBERTa-v3 prompt-injection (onnx), лексический классификатор как запасной |
| Поиск закодированных данных и скриптов | ✅ | пакет `decode`, рекурсивно до заданной глубины |
| Разбор системных bash-команд | ✅ | настоящий парсер bash (`mvdan.cc/sh`), анализ пайплайна |
| Итеративный анализ «команда → результат → команда» | 🟡 | рекурсивно декодируем вложенные слои; исполнение не эмулируется, разбор статический |
